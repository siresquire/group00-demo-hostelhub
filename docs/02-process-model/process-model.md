# Process model: HostelHub
## Context
5 students · 9 weeks · hall rules not confirmed yet
## Options considered
Waterfall · V-model · Incremental · XP · Timeboxing
## Decision
Incremental, 2-week timeboxes, with XP practices:
pairing on hard code, tests first, PR reviews.
## Why- needs will change once we interview the hall office- the client can try working software every 2 weeks- Paystack + SMS APIs exist: reuse, don't build
## Risks- structure decays → refactor in every increment
